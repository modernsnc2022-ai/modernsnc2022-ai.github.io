Shared Compute OAuth

Shared Compute OAuth is a private, operator-controlled integration used by GD Global to authorize Google Drive access for shared compute workflows running on approved cloud compute providers.

Purpose

The integration allows the authorized operator to move task inputs and verified outputs between Google Drive and compute workers. Google Drive is used as temporary working storage for these workflows; long-term archives are maintained separately under operator control.

Who can use it

This application is not a public SaaS product and is not offered for general user registration. Access is limited to accounts explicitly authorized by the operator.

Google Drive access

The integration may read, create, update, move, or delete Google Drive files only as required by an authorized workflow. Drive content is not sold, rented, or used for advertising.
